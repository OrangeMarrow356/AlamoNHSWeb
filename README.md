# AHS NHS Website

Starter homepage for the Alamogordo High School National Honor Society.

## Files

- `index.html` — homepage
- `css/style.css` — black/gold visual design
- `js/script.js` — mobile navigation and dynamic year

## GitHub Pages

Upload these files to your GitHub repository while preserving the folder structure.

The remaining pages and the private member/admin system will be added next.

## Important

The events and announcements on the homepage are placeholders. Replace them with information approved by the NHS adviser/school before publishing.
